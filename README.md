A comprehensive portfolio of static (SAST) and dynamic (DAST) web application security testing reports, vulnerability proof-of-concepts, and code-level remediation analyses.

## 🛠️ Core Security Competencies
* **Methodologies:** Static Application Security Testing (SAST), Dynamic Application Security Testing (DAST), Secure Code Review, Vulnerability Assessment.
* **Vulnerability Frameworks:** OWASP Top 10, CVSS Severity Scoring.
* **Key Attack Vectors Analyzed:** SQL Injection (SQLi), Cross-Site Scripting (XSS), Server-Side Request Forgery (SSRF), Broken Access Control (BAC), Command Injection.
